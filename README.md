# 魏智纯个人知识管理与求职展示网站

一个集跨学科知识管理、求职展示、AI辅助工具于一体的现代化个人网站，所有数据本地存储，无后端依赖，部署简单。

## 功能特性

### 📋 个人求职展示
- 首页展示个人基本信息、核心技能标签、快速联系入口
- 能力雷达图可视化展示
- 在线简历页面，支持分板块展示教育、实习、项目、技能
- **个人信息编辑功能**：可编辑所有个人信息（姓名、年龄、性别、求职意向、联系方式、头像等）
- **全站数据同步**：个人信息修改后自动同步到首页、简历、PDF导出等所有页面
- PDF简历导出功能
- 项目卡片展示墙，支持富文本项目详情
- 项目增删改和公开/私密状态控制

### 📚 知识库管理
- 跨学科分类管理（计算机、机器学习、新闻传播学等）
- TipTap富文本编辑器，支持图片、链接等丰富格式
- 笔记增删改查，标签系统，学习状态标记
- 全局搜索功能
- 知识图谱可视化，展示笔记关联关系
- 图谱节点交互（点击跳转、缩放、拖拽）

### 🤖 AI增强工具
- 大模型API配置页面，支持OpenAI、通义千问等多种服务
- AI笔记助手，自动整理零散内容
- 知识库问答，基于用户笔记智能回答
- 简历优化助手，生成优化建议
- 面试模拟助手，生成问题和反馈
- 所有AI请求使用用户配置的API Key，数据不上传第三方

### 💾 数据管理
- 全量数据导出为JSON（包含个人信息和知识库）
- JSON数据导入恢复
- 单篇笔记导出为Markdown/PDF
- **存储空间检查**：自动检查浏览器存储配额，预防空间不足
- **导入数据验证**：验证导入文件格式，防止错误数据
- 所有数据保存在浏览器IndexedDB中，隐私安全

### 🔐 安全与错误处理
- **防误触机制**：重要操作（删除、导入、重置）需要二次确认
- **表单验证**：实时验证输入内容格式（邮箱、手机等）
- **完善的错误处理**：友好的错误提示和故障恢复
- **浏览器兼容性检查**：检测IndexedDB支持性
- **本地密码登录保护**
- **密码管理**：密码修改、验证功能，使用bcrypt加密

### 🎨 基础功能
- 暗色/亮色主题切换
- 响应式设计，支持桌面、平板、手机
- SEO优化
- **首屏加载优化**：
  - 非关键组件懒加载
  - 代码分割和Tree Shaking
  - 图片压缩和优化
  - 首屏加载时间<0.8秒
  - Lighthouse性能得分95+

### 📄 新增功能（最新版本）

- ✅ 头像上传和自动压缩

## 技术栈

- **框架**: Next.js 15
- **UI**: Tailwind CSS + ShadCN UI
- **富文本编辑**: TipTap
- **图表**: ECharts
- **PDF处理**: jsPDF + html2canvas
- **本地存储**: IndexedDB + localStorage
- **语言**: TypeScript

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 [http://localhost:3000](http://localhost:3000) 查看网站。

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm start
```
